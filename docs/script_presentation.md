# สคริปต์วิดีโอนำเสนอ 5 นาที — โปรเจกต์แก้น้ำท่วมเชิงโครงสร้าง เมืองยะลา

> ผู้นำเสนอ 3 คน: **ฮิ / ซา / ลอฮ** (แบ่งบทสมดุล ~คนละ 100 วินาที)
> เน้น: **หลักการ/วิธีทำ** + **ทำถึงไหนแล้ว** · ครอบคลุมเกณฑ์ครบ 4 ข้อ

**[0:00–0:18] ซา :** ทุกปี เมื่อฤดูมรสุมมาเยือนภาคใต้ เทศบาลนครยะลาต้องเผชิญน้ำท่วมซ้ำซาก กระทบมากถึง 41 จาก 44 ชุมชน และทุกครั้ง เราก็แก้แบบเดิม — วางกระสอบทราย เร่งสูบน้ำ อพยพคน แล้วก็รอให้น้ำลด แต่พอปีหน้ามาถึง น้ำก็ท่วมที่เดิม ลึกเท่าเดิม
*[ฟุตเทจน้ำท่วมยะลา พ.ย.2568 + กระสอบทราย/เครื่องสูบ]*

**[0:18–0:35] ซา :** ดังนั้น หากเราสามารถรู้ได้ว่า "ควรแก้โครงสร้างของเมืองตรงไหน" เพื่อหยุดน้ำท่วมอย่างถาวร เราก็จะตัดวงจรนี้ได้ และนี่ คือจุดเริ่มต้นของโครงการของเรา

**[0:35–0:52] ฮิ :** ระบบวิเคราะห์พื้นที่ เพื่อแก้ปัญหาน้ำท่วมเชิงโครงสร้างของเมืองยะลา ด้วยการชี้จุดที่ควรสร้างแก้มลิง บ่อหน่วงน้ำ และปรับปรุงระบบระบายน้ำ
Assalamualaikum warahmatullah wabarakatuh
*[ขึ้นชื่อโครงการ + ช็อตเมือง 3D]*

**[0:52–1:30] ฮิ :** ทุกท่านครับ จากที่เราได้ลงพื้นที่สำรวจ พบว่า น้ำท่วมในเมืองยะลาไม่ได้เกิดแบบสุ่ม แต่น้ำจะไหลมารวมที่ "จุดต่ำเดิมๆ" ไปตามทางเดิม และล้นตรงที่ระบายน้ำไม่พอเหมือนเดิมทุกปี นั่นแปลว่า ปัญหาที่แท้จริงอยู่ที่ "โครงสร้างของเมือง" ไม่ใช่แค่ปริมาณน้ำ และผู้ที่จะใช้เครื่องมือของเรา คือสำนักการช่างและผังเมืองของเทศบาล ที่ต้องตัดสินใจว่า จะลงงบประมาณสร้างโครงสร้างป้องกันน้ำท่วมอะไร ตรงไหน ให้คุ้มค่าที่สุด
*[เปิดชั้น "น้ำท่วมซ้ำซาก GISTDA" + ภาพชุมชนริมน้ำ]*

**[1:30–1:45] ลอฮ :** แล้วเรารู้ได้อย่างไร ว่าควรไปแก้ตรงไหน? ขอเล่าวิธีทำงานของระบบเราแบบง่ายๆ เป็น 3 ขั้นตอนครับ
*[กราฟิก 3 ขั้นตอน]*

**[1:45–2:15] ลอฮ :** ขั้นแรก เราจำลองเมืองยะลาทั้งเมือง ลงในคอมพิวเตอร์ เป็นเหมือนเมืองจำลองสามมิติ ที่รู้ว่าตรงไหนสูง ตรงไหนต่ำ มีบ้านเรือนอยู่ที่ไหน ท่อระบายน้ำและเครื่องสูบน้ำอยู่ตรงไหน ทั้งหมดนี้เป็นข้อมูลจริงของเทศบาล อาคารกว่าสองหมื่นสองพันหลัง ฝาท่อระบายน้ำกว่าเก้าพันจุด และสถานีสูบสิบเอ็ดแห่ง
*[เปิด toggle ทีละชั้น: สถานีสูบ → ฝาท่อ → ทางน้ำ]*

**[2:15–2:48] ซา :** ขั้นที่สอง เราลองเทน้ำลงไปในเมืองจำลองนี้ น้ำก็จะไหลจากที่สูงลงที่ต่ำ แล้วไปขังตามแอ่งต่างๆ เหมือนน้ำจริงทุกอย่าง ทำให้เรามองเห็นล่วงหน้าได้เลยว่า ถ้าน้ำในแม่น้ำขึ้นมาเท่านี้ เมืองจะท่วมตรงไหน และลึกแค่ไหน โดยที่ไม่ต้องรอให้เกิดน้ำท่วมจริงก่อน
*[ตั้งแม่น้ำ 90 → กดจำลอง → น้ำขึ้นเต็มเมือง]*

**[2:48–3:25] ฮิ :** และขั้นที่สาม ซึ่งเป็นหัวใจของงาน พอเราเห็นภาพน้ำท่วมทั้งเมืองแล้ว เราก็มองหาสองอย่าง อย่างแรกคือ "จุดที่น้ำชอบไหลมารวมกันและขังลึก" จุดเหล่านี้แหละ ที่เหมาะจะทำเป็นแก้มลิงหรือบ่อเก็บน้ำ เพื่อดักน้ำเอาไว้ ก่อนไหลเข้าท่วมเมือง และอย่างที่สองคือ "ย่านที่น้ำระบายออกได้ช้า" เพราะอยู่ไกลเครื่องสูบ หรือมีท่อระบายน้ำน้อย ย่านพวกนี้ ก็ต้องเพิ่มท่อ หรือเพิ่มเครื่องสูบน้ำ
*[ซูมบริเวณน้ำสีเข้ม(ลึก)=จุดแก้มลิง · เปิดชั้นฝาท่อ/สูบ ชี้ย่านเบาบาง]*

**[3:25–4:00] ลอฮ :** แล้วตอนนี้ เราทำไปถึงไหนแล้ว? เราพัฒนาระบบวิเคราะห์นี้ เสร็จเป็นต้นแบบที่ใช้งานได้จริงแล้ว และที่สำคัญ เราได้ตรวจสอบความถูกต้องกับความเป็นจริงถึงสามทาง หนึ่ง ขอบเขตน้ำท่วมตรงกับภาพถ่ายดาวเทียมของจิสด้า สอง เราตรวจสอบความสูงของพื้นดินด้วยเลเซอร์จากดาวเทียมของนาซา และสาม โมเดลของเราทำนายเหตุการณ์จริงเดือนพฤศจิกายน 2568 ได้ตรง ผลวิเคราะห์จึงเชื่อถือและนำไปใช้ตัดสินใจได้
*[สลับ 2D เปิดชั้น GISTDA ทับโมเดล → การ์ดความโปร่งใส]*

**[4:00–4:35] ซา :** สำหรับแผนดำเนินงานหนึ่งปี — ไตรมาสแรก เติมข้อมูลภูมิประเทศความละเอียดสูงจากจิสด้า เพื่อระบุจุดต่ำให้แม่นระดับเมตร ไตรมาสสอง พัฒนาโหมดทดสอบทางแก้ ที่จำลองได้ว่า ถ้าวางแก้มลิงตรงนี้ น้ำท่วมจะลดลงกี่เปอร์เซ็นต์ ไตรมาสสาม จัดอันดับจุดที่คุ้มค่าที่สุดเทียบกับงบประมาณ และนำร่องเสนอจุดจริงร่วมกับเทศบาล และไตรมาสสุดท้าย รวบรวมเป็นแผนแม่บทแก้น้ำท่วมของเมือง ส่งต่อให้วิศวกรนำไปออกแบบก่อสร้างจริง
*[motion graphic ไทม์ไลน์ Q1–Q4 · Q2 ใส่ before/after แก้มลิง]*

**[4:35–4:52] ฮิ :** โครงการนี้เป็นไปได้จริง เพราะเรามีต้นแบบที่ใช้งานได้แล้ว บนข้อมูลจริง ต้นทุนต่ำด้วยเทคโนโลยีโอเพนซอร์ส และต่อยอดจากระบบที่เทศบาลมีอยู่ ทั้งยังตรงตามหลัก BCG Model ด้วยการแก้ปัญหาด้วยโครงสร้างที่เป็นมิตรต่อสิ่งแวดล้อมอย่างแก้มลิง เปลี่ยนงบซ่อมความเสียหายซ้ำทุกปี ให้เป็นงบลงทุนที่แก้ต้นเหตุได้จริง
*[before/after เมืองมีแก้มลิง น้ำไม่ท่วม]*

## 📌 คำ/วลีศัพท์เทคนิค (อธิบายให้กรรมการเข้าใจง่าย)
- **DEM** = ข้อมูลความสูงของพื้นดินทุกจุดในเมือง
- **Connectivity Flood Model** = น้ำไหลจากสูงลงต่ำ เติมแอ่งที่เชื่อมแม่น้ำ → คำนวณว่าจุดไหนจมเมื่อน้ำสูงเท่าไหร่
- **หาจุดแก้มลิง** = จุดที่น้ำบรรจบ+ท่วมลึก = แอ่งธรรมชาติเหมาะกักน้ำ
- **หาจุดระบายไม่พอ** = ย่านไกลสถานีสูบ + ฝาท่อน้อย
- **ตรวจสอบ 3 ทาง** = ดาวเทียม GISTDA · LiDAR ดาวเทียม ICESat-2 (NASA) · เหตุการณ์จริง พ.ย.2568
- **BCG Model** = แก้ด้วยโครงสร้างเป็นมิตรสิ่งแวดล้อม (nature-based) ยั่งยืน
