# Phase 1 — แผนจัดหาข้อมูล (Data Acquisition Plan)

> เป้าหมาย Phase 1 = เปลี่ยน "ข้อมูลนำเข้า" จากค่าประเมิน/สมมติ → ข้อมูลจริง
> เพราะความแม่นของแบบจำลองน้ำท่วม **ขึ้นกับข้อมูลนำเข้า มากกว่าตัวอัลกอริทึม**
>
> สถานะ: ✅ มีแล้ว/ทำได้เอง · 🟡 มีบางส่วน/คุณภาพต่ำ · 🔴 ต้องไปขอจากหน่วยงาน

---

## 1. ภูมิประเทศ (DEM) — สำคัญสุด ⭐⭐⭐

| รายการ | สถานะ | แหล่ง | หมายเหตุ |
|---|---|---|---|
| AW3D30 (30 ม.) | ✅ ใช้อยู่ | JAXA | หยาบ ±5 ม. มีตึก/ต้นไม้ปน — เป็นคอขวดความแม่นอันดับ 1 |
| Copernicus GLO-30 | 🟡 ดึงให้แล้ว | AWS open data | 30 ม. คุณภาพดีกว่าเล็กน้อย (สคริปต์ `scripts/fetch_copernicus_dem.py`) |
| FABDEM (bare-earth 30 ม.) | 🔴 ควรหา | Univ. Bristol (CC-BY-NC) | เอาตึก/ป่าออกแล้ว — เหมาะกับ hydrology กว่ามาก |
| **LiDAR DTM 1–2 ม.** | 🔴 **ต้องหา (สำคัญสุด)** | **กรมโยธาธิการและผังเมือง / GISTDA / จ้างบินสำรวจ** | ตัวเปลี่ยนเกม — ทำให้ความลึก/ขอบเขตในเมืองเชื่อได้จริง |

**สิ่งที่ต้องไปขอ:** LiDAR/แบบจำลองภูมิประเทศละเอียด (DTM) ของเขตเทศบาลนครยะลา ความละเอียด ≤2 ม.
หากไม่มี ขอ **ผลสำรวจระดับ (survey) จุดต่ำ/จุดวิกฤต** จากเทศบาลก่อนก็ช่วยได้มาก

---

## 2. โครงข่ายระบายน้ำเมือง — สำคัญมาก ⭐⭐⭐

เมืองท่วมหรือไม่ ขึ้นกับ "ความจุการระบาย" อย่างมาก — ตอนนี้ยังไม่มีในแบบจำลอง

| รายการ | สถานะ | แหล่ง |
|---|---|---|
| แนวคลอง/ทางน้ำ (OSM) | ✅ มี | OpenStreetMap |
| แนวท่อ/คู (สังเคราะห์จาก DEM) | 🟡 มี (ไม่ใช่ของจริง) | `yala_sewers.geojson` |
| **ท่อระบายน้ำจริง**: เส้นทาง + **ขนาดท่อ (Ø)** + **ระดับก้นท่อ (invert)** + ความลาด | 🔴 **ต้องหา** | **กองช่าง เทศบาลนครยะลา** |
| **สถานีสูบน้ำ**: ตำแหน่ง + **อัตราสูบ (m³/s)** + เกณฑ์เปิด-ปิด | 🔴 **ต้องหา** | **เทศบาล / สำนักการระบายน้ำ** |
| ประตูระบายน้ำ / แก้มลิง | 🔴 ต้องหา | เทศบาล / กรมชลประทาน |

**สิ่งที่ต้องไปขอ:** ผังท่อระบายน้ำ (as-built/GIS) + สเปกสถานีสูบ — มักอยู่ใน **City Digital Data Platform เทศบาลนครยะลา** ที่อ้างถึงอยู่แล้ว

---

## 3. แม่น้ำปัตตานี (Hydraulics) ⭐⭐

| รายการ | สถานะ | แหล่ง |
|---|---|---|
| แนวลำน้ำ | ✅ มี | OSM / กรมทรัพยากรน้ำ |
| **หน้าตัดลำน้ำ (cross-section) + ก้นน้ำ (bathymetry)** | 🔴 ต้องหา | **กรมชลประทาน (RID)** |
| ระดับตลิ่ง/เกณฑ์เตือนแต่ละสถานี | 🟡 มีบางส่วน (AAR: +14.00 ม.รทก.) | RID / PSU pbwatch |
| ค่าสัมประสิทธิ์ความขรุขระ (Manning's n) | 🟡 ประเมินจาก land use OSM | ปรับจริงตอน calibrate |

---

## 4. ตัวขับ (Boundary / Forcing) — เชื่อมเรียลไทม์ได้ ⭐⭐

| รายการ | สถานะ | แหล่ง / API |
|---|---|---|
| การระบาย/ปริมาณน้ำ **เขื่อนบางลาง** | ✅ ดึงสดได้ | ThaiWater api-v3 (dam_id=50) |
| **ฝนยะลา (ปัจจุบัน)** | ✅ ดึงสดได้ | Open-Meteo (ฟรี ไม่ต้อง key) |
| **ฝนพยากรณ์ 0–72 ชม.** | 🟡 ดึงได้ | Open-Meteo / TMD — ใช้ทำโหมดพยากรณ์ |
| เรดาร์ฝน nowcast | 🔴 ต้องต่อ | TMD / semet-radar |
| ระดับน้ำท่า real-time | 🟡 มีแหล่ง | PSU pbwatch / RID telemetry |
| **น้ำทะเลหนุน (tide)** ปากแม่น้ำ | 🔴 ต้องหา | กรมอุทกศาสตร์ทหารเรือ |
| **แผนปล่อยน้ำเขื่อน (ล่วงหน้า)** | 🔴 ต้องหา | **กฟผ. (EGAT)** |

**ผมต่อให้แล้ว:** เขื่อนบางลาง + ฝนปัจจุบัน → ดึงเข้าเครื่องจำลอง 3D ได้ (ปุ่ม "ใช้ค่าปัจจุบันจริง")

---

## 5. ข้อมูลตรวจสอบความแม่น (Validation) ⭐⭐

จำเป็นเพื่อ calibrate + พิสูจน์ว่าเชื่อถือได้

| รายการ | สถานะ | แหล่ง |
|---|---|---|
| น้ำท่วมซ้ำซาก GISTDA 2554–66 | ✅ มี | GISTDA |
| ขอบเขตน้ำท่วมดาวเทียม (รายเหตุการณ์) | ✅ มีบางส่วน (KMZ) | GISTDA |
| **รอยน้ำสูงสุด (high-water marks) เหตุการณ์ พ.ย. 2568** | 🔴 **ต้องเก็บ** | สำรวจภาคสนาม / ภาพถ่ายชุมชน / เทศบาล |
| ความลึก/ความเสียหายรายชุมชน (AAR) | 🟡 มีสรุป | เทศบาล / ปภ. |

**สิ่งที่ต้องไปขอ/เก็บ:** จุด+ระดับรอยน้ำท่วมจริง พ.ย. 2568 ให้มากที่สุด → ใช้ปรับจูนโมเดล

---

## 6. ข้อมูลความเสี่ยง/ผลกระทบ (สำหรับใช้งานจริง) ⭐

| รายการ | สถานะ | แหล่ง |
|---|---|---|
| อาคารเปราะบาง (รพ./โรงเรียน/สถานที่ราชการ) | 🔴 ต้องหา | เทศบาล / OSM (บางส่วน) |
| ศูนย์พักพิง/จุดอพยพ | 🔴 ต้องหา | ปภ. / เทศบาล |
| ประชากรรายพื้นที่ (สำมะโน/TAZ) | 🔴 ต้องหา | สำนักทะเบียน / NSO |
| ความสูงตึกจริง (จำนวนชั้น) | 🟡 ประเมินอยู่ | ใบอนุญาตก่อสร้างเทศบาล / LiDAR DSM |

---

## สรุป "3 อย่างที่ควรไปขอก่อน" (คุ้มสุด)
1. 🔴 **LiDAR/DTM ละเอียด** ของเขตเทศบาล — กรมโยธาฯ / GISTDA *(ความแม่นกระโดดมากสุด)*
2. 🔴 **ผังท่อระบายน้ำ + สเปกสถานีสูบ** — กองช่างเทศบาลนครยะลา
3. 🔴 **รอยน้ำสูงสุด พ.ย. 2568** — เก็บภาคสนาม/ภาพชุมชน *(ไว้ calibrate + พิสูจน์ความแม่น)*

> แนะนำ: ทำ **MOU/หนังสือขอข้อมูล** ผ่านเทศบาล ไปยัง RID / กฟผ. / GISTDA / TMD — ข้อมูลคือหัวใจของ Phase 1
