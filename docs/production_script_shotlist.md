# สคริปต์ VO + ชอตลิสต์ + สถานที่ถ่ายทำ (ฉบับใหม่)
## ระบบวิเคราะห์พื้นที่เพื่อแก้น้ำท่วม "เชิงโครงสร้าง" เมืองยะลา

> ใช้คู่กับ [storyboard_pitch_video.md](storyboard_pitch_video.md)
> **VO** = อ่านอัดตามคำต่อคำ · **อัดจอ** = บันทึกหน้าจอแอป · **ถ่ายจริง/สถานที่** = ฟุตเทจประกอบ
> แก่นเรื่อง: ไม่ใช่ "เตือนภัย" แต่คือ "ชี้จุดที่ควรแก้โครงสร้างเมือง — แก้มลิง/บ่อหน่วง/ท่อระบายน้ำ"

**VO (0:38–1:00):**

## 🎙️ ฉาก 2 — ไอเดีย: แก้ที่ "โครงสร้างเมือง" (1:00 – 1:55)

**VO (1:00–1:20):**
> "นี่คือเครื่องมือของเรา — ระบบวิเคราะห์พื้นที่ เพื่อแก้น้ำท่วมเชิงโครงสร้างของเมืองยะลา มันไม่ได้บอกแค่ว่าน้ำจะท่วม แต่บอกว่า เราควรแก้ตรงไหน"

**VO (1:20–1:40):**
> "จากข้อมูลภูมิประเทศ ทิศทางการไหล และระบบระบายน้ำจริง ระบบชี้จุดที่ควรทำ 'แก้มลิง' เพื่อกักเก็บน้ำ จุดที่ควรขุด 'บ่อหน่วงน้ำ' และจุดที่ท่อระบายน้ำไม่เพียงพอ ที่ต้องปรับปรุง"

**VO (1:40–1:55):**
> "แล้วใครใช้? สำนักการช่างและผังเมืองของเทศบาล ใช้ตัดสินใจว่าจะลงงบสร้างอะไร ตรงไหน ให้คุ้มที่สุด เปลี่ยนงบซ่อมหลังน้ำท่วม ให้กลายเป็นงบลงทุนที่แก้ปัญหาได้จริง"

**อัดจอ (พระเอกของฉาก):**
1. เปิด `localhost:5173` หน้า 3D เมืองยะลานิ่งสวย → กด **"จำลองสถานการณ์น้ำท่วม"** (1:00–1:10)
2. เล่นน้ำท่วมเบาๆ → กล้องเอียงให้เห็น **จุดต่ำที่น้ำไปรวม** (โทนน้ำเข้ม=ลึก) (1:10–1:20)
3. แทรกกราฟิกไอคอน 3 ทางแก้: **แก้มลิง · บ่อหน่วงน้ำ · ปรับท่อระบายน้ำ** (1:20–1:40)
**ถ่ายจริง/สถานที่:** ภาพเจ้าหน้าที่สำนักการช่าง/ผังเมืองดูแบบแปลน หรือ **อาคารเทศบาลนครยะลา** (1:40–1:55)

## 🎙️ ฉาก 3 — ทำถึงไหนแล้ว ⭐ (1:55 – 3:35)

**VO (1:55–2:20):**
> "เราสร้างฐานวิเคราะห์จากข้อมูลจริงของยะลาแล้ว ทั้งภูมิประเทศทั้งเมือง อาคารกว่าสองหมื่นสองพันหลัง ฝาท่อระบายน้ำกว่าเก้าพันจุด สถานีสูบสิบเอ็ดแห่ง รวมถึงแม่น้ำและลำคลองจริง"

**VO (2:20–2:50):**
> "เมื่อจำลองน้ำท่วม ระบบเผยให้เห็นชัดว่า น้ำไหลมารวมและท่วมลึกที่จุดต่ำจุดไหนบ้าง — จุดเหล่านี้ คือตำแหน่งที่เหมาะจะทำแก้มลิง หรือบ่อหน่วงน้ำ เพื่อดักน้ำไว้ก่อนที่จะไหลเข้าท่วมเมือง"

**VO (2:50–3:15):**
> "และเมื่อซ้อนข้อมูลระบบระบายน้ำลงไป ระบบชี้ย่านที่ระบายไม่ทัน — ย่านที่อยู่ไกลจากสถานีสูบ มีฝาท่อน้อย — ย่านเหล่านี้ คือจุดที่ต้องปรับปรุงท่อ หรือเพิ่มกำลังการสูบน้ำ"

**VO (3:15–3:35):**
> "และผลวิเคราะห์ทั้งหมดนี้ ตรวจสอบกับความจริงแล้ว ขอบเขตน้ำท่วมตรงกับภาพถ่ายดาวเทียมของจิสด้า และตรงกับเหตุการณ์จริงเดือนพฤศจิกายน สองพันห้าร้อยหกสิบแปด ผลวิเคราะห์จึงเชื่อถือได้"

**อัดจอ (ละเอียด):**
1. **(1:55–2:20) ฐานข้อมูลจริง:** หน้า 3D → เปิด toggle ทีละชั้น "โครงสร้างระบายน้ำ": สถานีสูบ → ฝาท่อ (จุดเหลืองเรียงตามถนน) → ทางน้ำเทศบาล
2. **(2:20–2:50) หาจุดทำแก้มลิง:** ตั้ง แม่น้ำ 90 → กดจำลอง → ปล่อยน้ำขึ้นเต็ม → **ชี้/ซูมบริเวณน้ำสีเข้ม (ลึก) ที่น้ำไปรวม** = candidate แก้มลิง
3. **(2:50–3:15) หาจุดระบายไม่พอ:** เปิดเฉพาะชั้น ฝาท่อ+สถานีสูบ → **ชี้ย่านที่จุดเบาบาง/ไกลสถานีสูบ** ขณะน้ำยังท่วมค้าง = จุดปรับปรุงระบาย
4. **(3:15–3:35) ตรวจสอบ:** สลับ 2D → เปิดชั้น **"เขตน้ำท่วมจริง GISTDA"** ทับโมเดล → เลื่อนไปการ์ด **"ความโปร่งใสของข้อมูล"** (CSI + การ์ดเหตุการณ์ พ.ย.2568)

**ถ่ายจริง/สถานที่:** แทรก **หอนาฬิกายะลา (วงเวียน)** ช่วงเล่าข้อมูลจริง ผูกกับเมือง
